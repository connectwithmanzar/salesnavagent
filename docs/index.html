Internal SDR tool · not on the Chrome Web Store

Export a Sales Navigator people list to Excel.

Load this folder in Chrome with Developer mode. Open a saved people list. Click Download Excel. Names and links stay on your computer — nothing is uploaded.

Download the folder (zip)

Chrome or Edge. Version 1.5.1. The navy card must say v1.5.1. Privacy. Chrome may warn that this is not from the Chrome Web Store — that warning is expected.

  1. 1

    Download and unzip

    Download the zip. Unzip it. You should see a folder named salesnav-list-save.

  2. 2

    Open Chrome extensions

    In the address bar paste chrome://extensions and press Enter. Turn Developer mode on (top right).

  3. 3

    Load the folder

    Click Load unpacked. Choose the unzipped salesnav-list-save folder (the one that contains manifest.json). Confirm Chrome and the navy card both say 1.5.1.

  4. 4

    Export a list

    Open a Sales Navigator people list. A navy card appears at the bottom right. Click Download Excel. The file lands in Downloads.

If Chrome shows a policy warning

Safety Check flags tools that are not listed on the Chrome Web Store. This one is loaded unpacked on purpose for the team. If the list still exports, you can keep using it. If you already had an older copy, remove it on chrome://extensions, then load this 1.5.1 folder.

What it will not do

It only works on saved people lists (/sales/lists/people/…), not search results. It stays on the list page and does not open each profile. Cancel stops immediately. List data is not sent anywhere. See privacy.
