Sales Nav List Save

Privacy

This is an internal team tool. It is not listed on the Chrome Web Store. List data stays on your computer.

What it reads

Only while you are on a Sales Navigator saved people list (/sales/lists/people/…) that you already opened while signed in. It reads names, titles, companies, locations, and profile links shown on that list.

What it does not do

It does not send list data to us, Google, or any other server. It does not open each LinkedIn profile. It does not hook network requests. The Excel file is written in the browser and saved to your Downloads folder.

Chrome warnings

Chrome Safety Check can warn that this is not from the Chrome Web Store. That is expected for a Load unpacked team tool. It does not mean the download is broken. Remove it any time from chrome://extensions.
